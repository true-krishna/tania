# tania-design-system

Letakkan folder ini sebagai `design/` di repositori TANIA (atau jadikan repositori sendiri), lalu daftarkan sebagai resource project di Multica.

    multica project resource add <project-id> --type github_repo --url <url-repo> --ref main --output json

Isi: `tokens/` (CSS dan Tailwind), `icons/` (React dan sprite SVG), `reference/` (guideline dan halaman contoh), `AGENTS.md` dan `CLAUDE.md` (aturan untuk agent).
